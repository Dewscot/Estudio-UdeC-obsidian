# Taylor - ejercicios tipo

## Ejercicio tipo: expansión de Taylor

### Desarrollo base
1. Identificar el centro \(a\).
2. Calcular derivadas.
3. Evaluar en \(a\).
4. Sustituir en:

$$
f(x)=\sum_{n=0}^{\infty}\frac{f^{(n)}(a)}{n!}(x-a)^n
$$

## Ejercicio tipo: radio de convergencia

### Desarrollo base
1. Identificar \(a_n\).
2. Aplicar cociente o raíz.
3. Obtener \(R\).
4. Revisar extremos.
